# Phase 1 records

These are the planning and status records of phase 1, the phase that built the text editor. They are kept for
reference and are not maintained: they describe the plan and the state of the code when phase 1 closed, and the code
has moved on since. To find your way through the current code, read the [codebase guide](../../codebase-guide.md); the
technical detail lives in the KDoc of the code itself.

- [The phase-1 specification](p1-text-editing-spec.md) was the contract of the phase: scope, conventions, the design
  principles the owner asked for, the planned behaviour of every module and the definition of done.
- [The work packages](p1-work-packages.md) split that contract into packages of work that were implemented in
  parallel, and record the decisions that refined the specification on the way, the review findings that were not
  adopted and the questions left for the owner.
- [The status report](p1-status.md) was written when phase 1 closed: what the phase delivers, how the definition of
  done was verified, the measurements of that time, the review findings that were fixed, the known limitations and
  the open questions.

The manual smoke test that phase 1 introduced is still in use and maintained as the
[manual smoke test](../../manual-test.md). Paths and section numbers inside these records refer to the repository
layout and the documents as they were at the time.
